# Вечер четверга — демонстрационный сайт

Адаптивный сайт московской студии керамики. Работают выбор занятий, сравнение двух-трёх форматов, запросы на курс и подарок, копирование текста и демонстрационный вид администратора. Форма ничего не отправляет, реальные бронирования не создаются.

## Локальный запуск

Откройте `index.html` или запустите `python -m http.server 8000`, затем откройте `http://localhost:8000`.

Проект статический, без установки зависимостей и сборки. GitHub Pages публикует корень ветки `main`.

## Актуализация

- `config.js`: цены, условия, даты проверки, источники и контакты.
- `assets/sources.json`: происхождение фотографий студии.
- `app.js`: подбор, сравнение и демонстрационная форма.
- `style.css`: адаптивное оформление.

Исходные данные проверены 25.10.2026. Акционная цена курса скрывается после 31.10.2026 по дате Москвы. Расписание и свободные места посетитель проверяет в действующей системе YCLIENTS; цены не синхронизируются автоматически.
